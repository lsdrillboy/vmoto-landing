# VMOTO — лендинг электробайков (Самуи · Панган)

Премиальный одностраничник для продажи электробайков VMoto CITI и CPx.
Статический сайт без сборки: HTML + CSS + ванильный JS.

## Запуск

```bash
python3 -m http.server 8734
```

Открыть http://localhost:8734 (конфиг для превью — в `.claude/launch.json`).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка всех секций (тексты — английские дефолты, переводятся на лету) |
| `style.css` | Все стили. Палитра и шрифты — в `:root` (акцент `--accent: #d94f3d`) |
| `main.js` | Меню, витрина моделей, слайдер «Для бизнеса», карта Leaflet, FAQ-байкер, отправка формы в Битрикс24 |
| `i18n.js` | Словарь EN / RU / TH / ZH + переключатель (EN — основной, выбор в localStorage) |

## Структура assets

```
assets/
├── video/          mp4: citi-360*, cpx-360* (вертушки цветов), promo, menu
├── poster/         постеры к видео и секвенциям (совпадают по именам)
├── gallery/        карточки «Галереи деталей» (led, batteries, brakes…)
├── business/       сцены слайдера «Решения для бизнеса» (retreat, rental, hotels)
├── img/            hero-bg / contacts-bg (+ -m мобильные), benefits-red, rider (FAQ)
└── src/            исходники и неиспользуемое — сайт на них не ссылается
```

## Пайплайн секвенций

```bash
# fps берите РОДНОЙ для видео (у hero.mp4 — 24): пересэмплирование даёт рваный шаг
ffmpeg -i video.mp4 -vf "fps=24,scale=1920:-2" f%03d.png
for f in f*.png; do cwebp -q 80 "$f" -o "${f%.png}.webp"; done
# мобильный комплект (960px) из готовых кадров:
for f in f*.webp; do dwebp "$f" -o t.png && cwebp -q 75 -resize 960 0 t.png -o "../hero-m/$f"; done; rm t.png
```

## Языковые версии

`/ru/` `/th/` `/zh/` — статические копии, которые генерирует
`node scripts/build-i18n.mjs` из index.html и словаря i18n.js
(hreflang проставляется на всех четырёх страницах). После правок
index.html или словаря перезапустите генератор и закоммитьте
обновлённые страницы.

## Интеграции

- **Форма → Битрикс24**: браузер шлёт POST `/api/lead` (serverless-функция
  Vercel, `api/lead.js`), которая создаёт контакт и сделку в воронке VMOTO.
  Вебхук хранится ТОЛЬКО в env Vercel: `B24_WEBHOOK_BASE` (и опционально
  `B24_PIPELINE_VMOTO`, по умолчанию 2). В клиентский код вебхук не класть.
- **Карта**: Leaflet + тайлы CARTO dark_nolabels (бесплатно, без ключей).
- **Шрифты**: Google Fonts — Exo 2 (дисплей), Manrope (текст/UI),
  Kanit + Noto Sans Thai (тайский), Noto Sans SC (китайский).

## Кэш

Ссылки на css/js в `index.html` имеют параметр `?v=N` — при правке файла
увеличьте номер, чтобы сбросить кэш браузера.

`vercel.json` отдаёт всё из `assets/` с заголовком `immutable` (кэш на год):
повторные визиты не ходят в сеть. Поэтому файл в `assets/` нельзя менять
по месту — новой версии давайте новое имя файла.
